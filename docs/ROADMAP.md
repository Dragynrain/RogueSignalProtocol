# Rogue Signal Protocol - Future Ideas & Roadmap

This document tracks potential future features and improvements. These are ideas under consideration, not commitments or promises.

---

## Implemented Features

These features have been completed and are available in the current version:

- **Ascension System** - 20 difficulty levels with scaling modifiers
- **Gamepad Support** - Full Xbox/PlayStation controller support
- **Linux Support** - AppImage, tarball, and AUR packages (Flatpak via Flathub in progress)

---

## Potential Future Features

### macOS Port
- Native macOS support
- Requires:
  - PyInstaller builds for macOS
  - Application Support directory handling
  - macOS-specific error dialogs
  - Code signing (optional but recommended)
  - Testing on macOS

### Additional Content
- New enemy types and behaviors
- Additional exploits and abilities
- More procedural level variety
- Extended narrative content
