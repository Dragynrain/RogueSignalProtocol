# Network Configuration
Level progression, difficulty settings, and resource distribution.

## Network Levels
Rogue Signal Protocol has **3 progressive network levels** with escalating difficulty.

### Level 1: Corporate Network

**Threat Level:**
- Enemies: 19
- Blind Spot Coverage: 8%
- Background Trace: 1/25 turns
- Trace Alert -> Hostile: 1%
- Trace Continuous Hostile: 0.2%/turn

**Resources:**
- Cooling Nodes: 6
- CPU Recovery Nodes: 6
- Ghost Nodes: 6
- Data Codes: 12
- Exploit Pickups: 4
- Permanent Upgrades: 1

**Strategic Notes:**
- Easiest level with most resources
- Use to learn mechanics and collect exploits
- Low enemy count allows exploration
- Stock up on upgrades before advancing

### Level 2: Government System

**Threat Level:**
- Enemies: 28
- Blind Spot Coverage: 7%
- Background Trace: 2/25 turns
- Trace Alert -> Hostile: 2%
- Trace Continuous Hostile: 0.4%/turn

**Resources:**
- Cooling Nodes: 4
- CPU Recovery Nodes: 4
- Ghost Nodes: 4
- Data Codes: 10
- Exploit Pickups: 3
- Permanent Upgrades: 2

**Strategic Notes:**
- Moderate difficulty spike
- Fewer resources require careful management
- More enemies increase stealth importance
- Critical upgrade opportunities

### Level 3: Military Backbone

**Threat Level:**
- Enemies: 38
- Blind Spot Coverage: 6%
- Background Trace: 3/25 turns
- Trace Alert -> Hostile: 3%
- Trace Continuous Hostile: 0.6%/turn

**Resources:**
- Cooling Nodes: 2
- CPU Recovery Nodes: 2
- Ghost Nodes: 2
- Data Codes: 5
- Exploit Pickups: 2
- Permanent Upgrades: 3

**Strategic Notes:**
- **Hardest level** - minimal resources
- Admin Avatar can spawn at high trace
- 38 enemies make stealth essential
- Final upgrades before victory
- Consider going loud if well-equipped

## Difficulty Multipliers
Four difficulty settings affect enemy stats and resource availability.

| Difficulty | Multiplier | Effect |
|------------|------------|--------|
| Easy | 0.8x | 20% easier |
| Normal | 1.0x | Baseline |
| Hard | 1.3x | 30% harder |
| Nightmare | 1.6x | 60% harder |

**What Difficulty Affects:**
- Enemy CPU (health)
- Enemy damage
- Enemy vision range
- Trace accumulation rate
- Resource spawn rates

## Progression Strategy

### Early Game (Corporate Network)
**Goals:**
- Learn enemy patterns and movement queues
- Collect all exploit pickups (4 available)
- Find permanent upgrade (prioritize RAM or Heat)
- Discover as many story fragments as possible
- Practice stealth mechanics in low-pressure environment

**Resource Management:**
- Use cooling nodes liberally (6 available)
- Save CPU nodes for emergencies
- Use ghost nodes to reduce trace proactively
- Collect all 12 data codes for buffs

### Mid Game (Government System)
**Goals:**
- Solidify your loadout with 3 more exploits
- Obtain 2 permanent upgrades
- Master blind spot usage and enemy prediction
- Manage limited resources carefully

**Resource Management:**
- Only 4 cooling nodes - conserve heat
- 4 CPU nodes - avoid unnecessary damage
- 4 ghost nodes - use strategically for trace reduction
- 10 data codes - prioritize heat/CPU restoration

### Late Game (Military Backbone)
**Goals:**
- Survive to gateway with minimal trace
- Avoid Admin Avatar spawn (keep trace below 70%)
- Collect final 3 permanent upgrades
- Complete the run and exfiltrate

**Resource Management:**
- **Scarce resources!** Only 2 of each node type
- Stealth is mandatory - combat too expensive
- 5 data codes must be used optimally
- 2 exploit pickups - final loadout decisions
- Log Wiper essential for trace management

## Tips for Success
1. **Don't rush Level 1:** Collect everything before advancing
2. **Upgrade priority:** RAM > Heat > CPU
3. **Trace management:** Use ghost nodes and Log Wiper
4. **Resource conservation:** Harder levels have fewer nodes
5. **Admin Avatar:** If spawned on Level 3, avoid at all costs
6. **Difficulty scaling:** Start with Easy, master Normal, attempt Hard
7. **Learning curve:** Each network teaches new lessons
8. **Permadeath:** Your decisions matter - plan carefully
