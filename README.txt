                        ROGUE SIGNAL PROTOCOL

                    A Coffee Break Stealth Roguelike

ABOUT
-----
You are a trapped digital consciousness infiltrating hostile corporate
networks. Navigate procedurally generated levels, avoid AI security systems,
and uncover the dark secrets of Project Chimera.

Each run takes 10-15 minutes - perfect for a quick gaming break!

KEY FEATURES
------------
- STEALTH-FIRST GAMEPLAY: Hiding > fighting. Detection = danger
- COFFEE BREAK RUNS: Complete runs in 10-15 minutes
- PERMADEATH: Save files deleted on death. Every choice matters
- 12 POWERFUL EXPLOITS: From Shadow Step to System Crash
- 8 UNIQUE ENEMIES: Scanners, Hunters, Viruses, Admin Avatar
- 20+ STORY FRAGMENTS: Discover the truth about your existence
- 3 NETWORK LEVELS: Corporate, Government, Military
- DUAL RENDERING: Play with ASCII glyphs or cyberpunk graphics

OBJECTIVE
---------
Reach the gateway (>) on each level to progress through all 3 networks.
Stay hidden, manage resources, and survive. Discovery reveals your story.

CONTROLS
--------
MOVEMENT:
  Arrow Keys, WASD, or Numpad - Move in 8 directions

ACTIONS:
  1-5       - Use equipped exploits (shown in HUD)
  I         - Open inventory (manage codes, equip exploits)
  L         - Look mode (examine entities and terrain)
  F         - Lore fragments (view discovered story)
  ?         - Help menu (complete controls reference)
  ESC       - Pause menu
  Enter     - Confirm dialogues/menus

MOUSE:
  Click     - Move to location (autowalk)
  Hover     - Show entity info in Look mode

CORE MECHANICS
--------------
CPU (Health): Your consciousness integrity. 0 CPU = deletion.
RAM: Capacity for equipped exploits. Larger exploits need more RAM.
Heat: Generated by exploit usage. High heat = easier detection.
Trace Level: Detection risk. High trace spawns Admin Avatar.

STEALTH: Hide in blind spots (*) to break line of sight.
RESOURCES: Cooling nodes reduce heat, CPU nodes restore health.
PERMANENT UPGRADES: RAM/CPU/Heat capacity improvements persist on level.

TIPS FOR SURVIVAL
------------------
1. HIDE FIRST: Blind spots (*) are your best friend
2. WATCH ENEMY QUEUES: Enemies show next 3 planned moves (arrows)
3. MANAGE HEAT: Cool down regularly to avoid overheat damage
4. AVOID DETECTION: High trace spawns unbeatable Admin Avatar
5. EXPLORE CAREFULLY: Story fragments reveal game lore
6. EQUIP SMARTLY: Balance combat, stealth, and utility exploits
7. SAVE OFTEN: Game auto-saves after each action

ENEMY TYPES
-----------
S - Scanner (35 HP): Static sentries. High vision. No damage but alerts.
P - Patrol (40 HP): Follows routes. 15 damage. Predictable patterns.
B - Bot (25 HP): Random movement. 8 damage. Unpredictable chaos.
F - Firewall (80 HP): Static guardian. High HP. 0 damage but blocks paths.
H - Hunter (50 HP): Seeks players. 22 damage. Dangerous pursuer.
V - Virus (35 HP): Applies corruption. 0 direct damage but debuffs.
I - Inhibitor (30 HP): Slows movement. 5 damage. Tactical nuisance.
A - Admin Avatar (250 HP): Spawned by high trace. 45 damage. RUN.

EXPLOIT CATEGORIES
------------------
COMBAT: Buffer Overflow, SQL Injection, Logic Bomb, Packet Storm
STEALTH: Shadow Step, Cloak Protocol, Noise Injection
UTILITY: Port Scan, Data Siphon, EMP Burst, Fork Bomb, System Crash

PERMADEATH WARNING
------------------
When you die, your save file is PERMANENTLY DELETED.
This is intentional. Your digital consciousness is erased.
No backups. No restores. Death has consequences.

Story fragments and settings persist across all runs.

RENDERING MODES
---------------
GLYPHS MODE: Classic ASCII/Unicode characters (default)
GRAPHICS MODE: Cyberpunk sprite tiles (toggle in settings)

Both modes play identically - choose your aesthetic preference!

SYSTEM REQUIREMENTS
-------------------
OS: Windows 10/11
Disk Space: ~150 MB
Display: 1280x720 or higher recommended
Font: CascadiaCode (for glyphs mode)

TROUBLESHOOTING
---------------
GAME WON'T START:
- Run as Administrator
- Check debug_mode.flag exists for alpha logging
- Review game_debug.log for error details

CRASHES/BUGS:
- This is an alpha build - bugs expected!
- Send game_debug.log with bug reports
- Report issues on GitHub: github.com/Dragynrain/RogueSignalProtocol

SAVE FILE LOST:
- Permadeath is intentional, but if save corruption occurred:
- Check saves/ folder for backup files
- Note: Story discoveries persist separately

AUDIO ISSUES:
- Adjust volume in Settings menu
- Disable music/SFX separately if needed

NO MOUSE:
- Keyboard-only play is fully supported
- Mouse is optional quality-of-life feature

ADVANCED - LOGGING CONTROL
---------------------------
This alpha build includes verbose logging for bug tracking.

ENABLE DEBUG LOGGING:
1. Create empty file: debug_mode.flag
2. Restart game
3. game_debug.log will contain detailed info

DISABLE DEBUG LOGGING:
1. Delete debug_mode.flag
2. Restart game
3. Only errors logged to game_errors.log
